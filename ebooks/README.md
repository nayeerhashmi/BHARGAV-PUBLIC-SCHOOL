# E-book Library Folder

Upload student e-books here as PDF files using GitHub.

## How to add a book
1. Open the repository and the `ebooks/` folder.
2. Choose **Add file → Upload files**.
3. Drag and drop the PDF files and commit the changes.
4. Add each book's title and link as a card in `pages/school/guest-book.html`, using a link such as `../../ebooks/book-file.pdf`.

Keep filenames short and simple, for example `class-6-science.pdf`. Only upload materials the school has permission to distribute.
