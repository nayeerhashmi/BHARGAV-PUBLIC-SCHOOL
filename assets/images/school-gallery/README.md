# School photo slideshow

Upload authorised school photographs to this folder using filenames `slide-1.jpg`, `slide-2.jpg`, `slide-3.jpg` and so on, up to `slide-12.jpg`. The homepage detects the photos, rotates every five seconds, and includes previous/next arrows and dots. If none are present, the current school logo is used as a fallback. Landscape JPG photos work best. Confirm permission to publish images, especially photographs of children.
