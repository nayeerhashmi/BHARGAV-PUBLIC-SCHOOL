# Academic Calendar

This folder contains the standalone Academic Calendar 2026–27 page for Bhargav Public School.

- `index.html` contains the calendar page and information sections.
- `calendar.css` contains styles specific to this page.
- `calendar.js` renders the month-by-month calendar and date markers.

Holiday entries for 2026 are based on the J&K Government holiday order. The 2026–27 assessment windows are indicative only and must be confirmed by the school. Add the official J&K holiday order for 2027 and any school circulars when available.
